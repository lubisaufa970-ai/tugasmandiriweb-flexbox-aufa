Mengapa menggunakan Flexbox?

Alignment

Atur posisi item pada main axis dan cross axis.

Flexible Size

Distribusikan ruang tanpa bergantung pada ukuran kaku.

Responsive

Biarkan item membungkus ketika ruang mulai terbatas.

Consistent Gap

Atur jarak antarelemen secara konsisten dengan gap.

Tentang Workshop

Satu layout, banyak ukuran layar.

Flexbox membantu komponen beradaptasi tanpa menyusun ulang HTML.
